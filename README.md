## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
Generates optimized static bundles in the `dist/` directory ready for deployment on GitHub Pages, Vercel, Netlify, or Firebase Hosting.
